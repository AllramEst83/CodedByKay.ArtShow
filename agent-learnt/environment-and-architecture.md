# Environment & Architecture Notes

## App Structure & Serving Model
- **Publish Root:** Netlify is configured to publish `.` directly. Do not introduce complex build outputs (`dist/`) unless explicitly requested.
- **Media Serving, current architecture (as of 2026-09-11):** this site stores no raw media at all. Images live on **Cloudflare R2** (`https://kaysartshow.fyi`, a custom domain — never the bucket's `r2.dev` URL), video on **YouTube** (embedded via `youtube-nocookie.com/embed/<id>`). `data/artwork.json`'s `imageUrl`/`thumbnailUrl`/`videoUrl` are already-absolute URLs pointing at those hosts, written by the sibling `CodedByKay.ArtShow.CLI` tool's `Publish` command — this repo never generates them itself. The frontend (`js/main.js`) fetches that JSON file directly as a static asset (`netlify.toml`'s `publish = "."` exposes it at that path) — **there is no serverless function or edge function left in this repo**; both `netlify/functions/image.js` and `netlify/edge-functions/media-gate.js` were deleted once media moved fully off Netlify, and the entire `netlify/` folder is gone (the JSON moved from `netlify/functions/data/artwork.json` to plain `data/artwork.json` 2026-09-11 so its path stopped implying a function was involved). Don't re-add any of it without a real reason — it existed only to proxy/gate `assets/drawings/`, which no longer exists.
  - **History, for context:** this is the second serving model, not the first. Originally every image/video byte was proxied through `netlify/functions/image.js` (Lambda, base64-encoded, ~6MB response ceiling) plus a hand-rolled video-streaming function — both were retired in favor of serving `assets/drawings/**` as plain static files from the Netlify CDN (full Range support, no size limits), gated by `media-gate.js` checking Origin/Referer against `ALLOWED_ORIGINS`. That static-Netlify-CDN model was itself retired 2026-09-11 in favor of the R2/YouTube model above once the storage migration (`docs/archive/storage-migration-plan.md`) completed — `assets/drawings/` and `ALLOWED_ORIGINS`/`media-gate.js` no longer exist. If you see either referenced anywhere else in this repo's docs, it's stale.
  - **Thumbnails:** for images, `thumbnailUrl` is a pre-generated R2 object (`thumbs/<year>/<slug>-600w.webp`), created once at CLI upload time — not derived per-request the way Netlify Image CDN used to. For video, `thumbnailUrl` is YouTube's own auto-generated thumbnail (`img.youtube.com/vi/<id>/hqdefault.jpg`) — no upload involved.
  - **No app-code hotlink gate remains.** If protection is wanted later, it's a Cloudflare dashboard setting on the R2 custom domain (hotlink rules), not a Netlify edge function — Cloudflare already sits in front of that traffic.
- **Editor Isolation:** Any local dev tools or draft editors must be completely isolated or omitted from production deployment if not meant to be public.
